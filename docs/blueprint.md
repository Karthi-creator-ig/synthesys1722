# **App Name**: Synthesys

## Core Features:

- Knowledge Extraction Tool: An AI tool that processes uploaded documents and generates a searchable vector index for RAG-based querying.
- Intelligent QA Chatbot: A chat interface where users ask questions and the AI fetches specific answers directly from the provided documentation.
- Semantic Source Citations: The AI response highlights and links directly to the specific section of the document used as the ground truth.
- Document Management Hub: Upload, categorize, and delete PDFs or text files to be used for retrieval, with status stored in a centralized database.
- Live Sync Markdown Editor: Draft new internal documentation directly in the browser that instantly integrates into the AI knowledge base.

## Style Guidelines:

- Primary color: Deep Indigo (#4050A6) used for navigation and buttons to convey intelligence and reliability.
- Background color: A serene Off-White (#F6F7F9) providing a clean, paper-like surface for focus-intensive reading.
- Accent color: Vibrant Sky Blue (#47A0D9) for highlights, source citations, and active chat states.
- Font pairing: 'Inter' for UI controls and headlines to maintain a modern tech feel, with 'Literata' for document body text to optimize long-form legibility.
- Minimalist monolinear icons with subtle stroke weights to keep the interface feeling light and secondary to the content.
- A flexible two-pane layout featuring a collapsible document sidebar and a focused central chat/viewer area.
- Graceful fade-and-slide transitions for incoming chat bubbles and smooth progress bars during document indexing.
